# ticketAPP
A theatre ticketing app designed for arts engagement
The target audience includes theatre managers, box-office staff, marketing teams, and venue administrators. It also serves production companies needing streamlined scheduling, seating, and customer engagement to enhance operational efficiency and deliver smooth experiences for patrons
System goals: An aim to bridge the gap between the consumer side and the managerial side of arts administration. A software that will be all encompassing the features a company needs to track ticketing. Encourage consumers to see more shows.

Key Features for consumers include: booking tickets, and an upcoming events locator/map
Key Features for Admin include: managing backend and logging ticket revenue, connecting digital bookings to online bookings, and partnering with other theatres to boost engagement
